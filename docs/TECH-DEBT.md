## Sprout / Wrap Register

## Debt Budget & Broken-Windows Policy

- Une fenêtre cassée dans un fichier que touche la PR se répare dans cette PR.
- Une fenêtre cassée ailleurs devient, avant le merge, une issue labellisée `tech-debt` ; sa ligne au registre ci-dessus pointe vers l'issue. Le code ne porte ni `TODO`, ni `FIXME`, ni `HACK`.
- Budget : une issue `tech-debt` traitée pour 5 PR de fonctionnalité mergées.
- Une issue `tech-debt` fermée passe sa ligne du registre à `done`.

## Adopted Conventions

- Une politique (accès à un projet, messages de refus) vit à un seul endroit ; un use-case l'appelle, il ne la recopie pas.
- Une valeur énumérée du domaine (plan, rôle) se définit une fois en tuple `as const` ; types, schémas zod et contrats en dérivent.
- Un problème HTTP commun à plusieurs routes vit dans `platform/problem.ts` ; un problème propre à un module vit dans sa couche `presentation`.
