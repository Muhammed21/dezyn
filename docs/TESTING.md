# Tests

## Test Strategy

- Unitaires (`pnpm test`) : domaine et contrats, sans base. 442 tests.
- Intégration (`pnpm test:integration`) : l'app entière en mémoire (`app.request()`), sur une vraie PostgreSQL, un fichier par comportement d'ADR. 510 tests.
- Mutation (`pnpm --filter @repo/api mutation`, Stryker en place, en local seulement) : mesure la force des tests ; seuils 90 / 100 %, sans blocage. `--mutate <fichiers>` restreint le run aux fichiers touchés.
- Bench (`pnpm bench`) : `apps/api/bench/*.bench.ts`, sur une vraie PostgreSQL ; voir [PERFORMANCE.md](PERFORMANCE.md).
- Vert = les deux suites en CI (`ci.yml`).

- [x] Mesurer le score de mutation du module proposal : 97,5 % (794 mutants). Deux tests de concurrence tuent les 5 survivants tuables : une proposition remplacée pendant la validation de son lot reste Remplacée (statut relu sous verrou), et deux premières écritures simultanées de la même IA vont dans le même lot (`openBatchOf` rend le lot déjà ouvert). Les 20 autres sont équivalents : le code `not_found` de `listBatches` et `batchOf` (la route ne le lit pas), les gardes `found === undefined` et `batch === undefined` (l'espace est alors déjà absent), le `?.` du statut verrouillé (le verrou rend toutes les propositions du lot), les codes `invalid_proposition` et `unchecked_tokens` (les appelants ne testent que l'autre code), la clé du verrou consultatif et la portée du `for update` de `pendingOf` (un verrou plus large sérialise les mêmes écritures), le message, le `?.` et le test `instanceof` de `RolledBack` (une erreur inattendue rend 500 dans tous les cas), la garde d'UUID de `review-routes` (un identifiant absent ne correspond à aucune ligne, la route rend déjà 404)
- [x] Mesurer le score de mutation du module space : 97,3 % (664 mutants). Le seul survivant tuable, le `type` du problème 503 d'un email d'invitation non envoyé, est tué. ## CI Gates

- `ci.yml` : `pnpm test` et `pnpm test:integration` bloquent le merge.
- Stryker tourne en local seulement : sur un diff de 10 fichiers, le run dépasse 60 min en CI, même sans les mutants statiques.
- `perf-pr.yml` et `perf-main.yml` comparent les benchs à la référence de `main`, à titre informatif, sans jamais bloquer ; un bench sans échantillon fait échouer le job.
